Turning resumes into structured candidate data.

نحوّل السير الذاتية إلى بيانات مرشحين منظّمة.

An automated pipeline that reads resumes in Arabic and English, extracts a structured candidate profile, and — when HR adds a job description — scores every uploaded resume against it.

نظام آلي يقرأ السير الذاتية بالعربي والإنجليزي ويستخرج منها ملف مرشح منظّم، وإذا أضاف فريق الموارد البشرية وصف وظيفة، يرجع لكل سيرة مرفوعة درجة مطابقة معها.

How resume extraction works

كيف يعمل استخراج السير الذاتية

1

Upload a resume

رفع السيرة الذاتية

Upload a CV in Arabic or English through the web interface.

يرفع المستخدم السيرة بالعربي أو الإنجليزي عبر واجهة الويب.

2

Extraction runs

تشغيل الاستخراج

FastAPI processes the file and sends it to Qwen2.5-14B served on vLLM.

تعالج FastAPI الملف وترسله لنموذج Qwen2.5-14B المنشور على vLLM.

3

Get a structured profile

استلام ملف منظّم

A JSON candidate profile comes back: name, experience, education, skills, certifications, and languages.

يرجع ملف JSON للمرشح: الاسم، الخبرات، التعليم، المهارات، الشهادات، واللغات.

How job matching works

كيف تعمل مطابقة الوظائف

1

Add a job description

إضافة وصف الوظيفة

HR adds a job description and uploads several resumes at once.

يضيف فريق الموارد البشرية وصف الوظيفة ويرفع عدة سير ذاتية دفعة وحدة.

2

Matching runs

تشغيل المطابقة

FastAPI compares each resume against the job description using Qwen2.5-14B served on vLLM.

تقارن FastAPI كل سيرة ذاتية بوصف الوظيفة باستخدام نموذج Qwen2.5-14B المنشور على vLLM.

3

Get match results

استلام نتائج المطابقة

Each candidate gets a match score, matched skills, and missing skills.

يحصل كل مرشح على درجة المطابقة، والمهارات المتطابقة، والمهارات الناقصة.

Why Qwen2.5-14B was deployed

ليش اخترنا Qwen2.5-14B للنشر

  • Best F1 on English resumes (90.52%), ahead of GPT-5.6 Sol (84.97%).
  • Close to GPT-5.6 Sol on Arabic: 96.87% F1 vs 97.05%.
  • Lowest hallucination in both languages: 0.89% English, 0.00% Arabic, while Qwen2.5-7B reached 48.84% on Arabic.
  • No per-token API cost: it runs self-hosted on a single GPU.
  • أعلى F1 على السير الإنجليزية (90.52%)، متقدم على GPT-5.6 Sol (84.97%).
  • قريب جدًا من GPT-5.6 Sol بالعربي: 96.87% مقابل 97.05%.
  • أقل نسبة هلوسة في اللغتين: 0.89% إنجليزي و0.00% عربي، بينما وصل Qwen2.5-7B إلى 48.84% بالعربي.
  • بدون تكلفة لكل توكن: يشتغل باستضافة ذاتية على معالج رسومات واحد.
